# ❓ **FAQs（よくある質問）**

**Q: $STOKEは取引できますか？**  
A: はい、$STOKEは取引可能で代替性のあるトークンです。

**Q: $STOKEを売却したら報酬はどうなりますか？**  
A: 売却時点までに蓄積された報酬は、あなたのステーキングアドレスに紐づけられており、次回の配布期間に請求可能です。ただし、$STOKEを売却した瞬間から報酬の蓄積は止まり、$TOKEへの交換権も失われます。

**Q: ステーキング後、報酬が発生し始めるまでどれくらいかかりますか？**  
A: ステーキングした後、UTC午前0時のスナップショットを**2回連続で完了**する必要があります。つまり、**ステーキング完了から最低24時間＋最初のスナップショット**が必要です。  

例：UTC午後1時にステークした場合、00:00 UTCに最初のスナップショットを受け、その後さらに24時間待って2回目のスナップショットを完了する必要があります。

**Q: FlexプールでのADAの毎日配布は何に基づいて決まりますか？**  
A: Primeプールでの15% APRを確保した上で、残りの投資収益がFlexプールのADA報酬として分配されます。

**Q: $STOKEの残り枠（キャパシティ）はどこで確認できますか？**  
A: Tokeoアプリ内でプールの利用状況が表示されます。さらに、500,000 $TOKE/$STOKE以上保有しているユーザーには、新たな$STOKEが流通に入った際に通知が届きます。

**Q: $STOKEの流動性プールはありますか？**  
A: チームが公式に流動性プールを提供することはありません。流通している$STOKEはすべてコミュニティの手に委ねられています。

**Q: PrimeとFlexの両方のプールにステーキングできますか？**  
A: はい、一部の$TOKEをPrimeプールに、残りをFlexプールにステーキングすることが可能です。ただし、同じ$TOKEを**同時に両方にステーキングすることはできません**。
