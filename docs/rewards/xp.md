# 🧠 **Tokeo XP（TXP）プログラム**  

Tokeo Rewards Programでは、アプリ内のアクティビティに基づいてTXP（Tokeo Experience Points）が付与されます。

---

## 🔑 主な特徴

- **アクティビティに応じてTXPを獲得**  
　Tokeoアプリ内での行動に応じてユーザーにTXPが割り当てられます。

- **$TOKE保有者にはブースト報酬**  
　自身のアクティビティに加え、他のユーザーのアクティビティからも、保有している$TOKE量に応じて追加のTXPを獲得できます。

- **TXPはADAと交換可能に**  
　アプリ内で発生した手数料の25％がTXP報酬用としてプールされ、将来的にTXPをADAに交換できるようになります。
